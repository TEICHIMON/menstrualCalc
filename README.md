# 周期记录

月经周期记录与预测工具。移动端优先的 PWA，Vue 3 + Vite + Vant + Supabase。

## 功能

- **今天页**：当前周期天数、所处阶段（经期/卵泡期/易孕期/黄体期）、下次月经预测（含浮动区间）、经期开始/结束打卡、临期提醒横幅
- **日历**：实际经期（实色）、预测经期（虚线）、易孕期（浅绿）、排卵日（深绿）标记；点击任意日期可打卡或修正经期记录
- **统计**：周期长度趋势、每次经期天数、症状/心情频次
- **打卡**：流量、痛经程度、头晕程度、心情、症状、备注
- **健康页**：每天记录各设备屏幕时间（设备列表可配置）、锻炼（模式/时长/平均心率/卡路里，一天可多条）、头晕程度；温和的每周小结与连续记录天数
- **关联趋势图**：统计页展示近 30 天 头晕 × 屏幕时长 × 锻炼时长 同轴对比，经期日以底色标出，帮助发现头晕与生活方式的关联
- **颈椎休息提醒**：可选，9:00~21:00 间按设定间隔提醒活动颈椎（应用打开时生效），并附放松动作指引
- **CSV 导入/导出**：支持从小米运动健康等 App 导出的 CSV 导入历史经期与运动记录（列映射式，自动识别常见列名，自动去重）

## 预测算法

- 下次月经 = 最近 6 个有效周期的加权平均（越近权重越高），浮动区间取 ±1 个标准差
- 异常周期剔除：<15 或 >60 天，或偏离均值 2σ 以上（样本 ≥4 时）
- 排卵日 = 预测经期 − 黄体期天数（默认 14，可在设置调整）；易孕期 = 排卵日前 5 天 ~ 后 1 天
- 有效周期不足 2 个时按 28 天估算并在界面标注
- 周期 <21 / >35 天、经期 >7 天时显示温和提示（非医疗建议）

核心算法在 [src/lib/cycle.ts](src/lib/cycle.ts)，纯函数，单测见 `src/lib/cycle.test.ts`（`npm test`）。

## 运行

```bash
npm install
npm run dev
```

### 两种模式

- **本地模式**（默认）：不配置任何东西即可用，数据存浏览器 localStorage，仅限本设备
- **云同步模式**：多设备同步。步骤：
  1. 在 [Supabase](https://supabase.com) 创建项目
  2. 在 SQL Editor 中依次执行 `supabase/migrations/` 下的所有 SQL 文件（001、002…）
  3. 复制 `.env.example` 为 `.env.local`，填入项目 URL 和 anon key（Project Settings → API）
  4. 重启 dev server，注册账号登录

## 从小米手环导入历史数据

1. 打开「小米运动健康」App：**我的 → 设置 → 个人信息与权限 → 行使个人信息权利 → 导出个人数据**，勾选经期数据提交
2. 小米会把压缩包发到邮箱，解压得到 CSV
3. 在本应用 **设置 → 数据导入** 选择该 CSV，确认开始/结束日期列后导入

## 部署

```bash
npm run build   # 产物在 dist/，纯静态文件
```

推送到 `main` 后，GitHub Actions 会完成代码校验，并通过 Docker Compose 自动部署到 VPS。首次部署所需的 GitHub Secrets、Caddy 和 VPS 配置见 [docs/deployment.md](docs/deployment.md)。

也可以把 `dist/` 部署到其他静态托管。需要 HTTPS 才能安装 PWA（添加到主屏幕）。
